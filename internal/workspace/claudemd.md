# ws workspaces

Each directory here is a workspace made by `ws`, a CLI that gives each
agent its own disposable copy of git repos. You are probably working in one.

Before you run `ws`, run `ws llm` and follow its rules.

- Use only `ws machine` commands, and `ws review` to get your work
  reviewed. The other `ws` commands are for people and the desktop app.

- Removing a workspace deletes everything in it, whatever its git state.
  Push, or copy out, anything worth keeping.
- Don't remove, stop, or work in a workspace you didn't create unless told
  to, and never run `ws restart` unless told to.
